| T-01-01   | Information Disclosure | .env file                                                | mitigate    | .gitignore enforces .env exclusion; .env.example has placeholder values only — verified in Task 2 acceptance_criteria                                                     |
| T-01-02   | Tampering              | nuxt.config.ts runtimeConfig                             | mitigate    | mongoUri and jwtSecret MUST be top-level runtimeConfig keys, never under runtimeConfig.public; violating this exposes secrets to browser bundles                          |
| T-01-03   | Elevation of Privilege | MongoDB connection string                                | mitigate    | Use least-privilege MongoDB user for the hearth database; Atlas: readWrite role on hearth DB only; no cluster-admin                                                       |
