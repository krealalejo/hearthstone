<threat_model>

## Trust Boundaries

| Boundary                     | Description                                                                 |
| ---------------------------- | --------------------------------------------------------------------------- |
| Browser → /api/auth/register | Untrusted email + password from unauthenticated user                        |
| Browser → /api/auth/login    | Untrusted credentials; timing-safe comparison required                      |
| Browser → protected /api/\*  | JWT cookie sent automatically; middleware must validate before handler runs |
| /api/auth/refresh → Nitro    | Refresh token cookie from browser; no revocation list (D-09)                |

## STRIDE Threat Register

| Threat ID | Category               | Component                                                       | Disposition | Mitigation Plan                                                                                                                                       |
| --------- | ---------------------- | --------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-02-01   | Spoofing               | POST /api/auth/login                                            | mitigate    | bcryptjs.compare() is timing-safe; return identical 401 message for wrong-password and unknown-email to prevent user enumeration                      |
| T-02-02   | Tampering              | JWT payload                                                     | mitigate    | jose requires explicit alg HS256 in setProtectedHeader — no algorithm negotiation from token header; secret is minimum 32 chars from .env             |
| T-02-03   | Elevation of Privilege | httpOnly cookie theft via XSS                                   | mitigate    | httpOnly: true on both cookies — JavaScript cannot read them; sameSite: lax blocks cross-site POST from external origins                              |
| T-02-04   | Information Disclosure | /api/auth/me without token                                      | mitigate    | auth.ts middleware returns 401 before me.get.ts handler runs; URL skip list does NOT include /api/auth/me                                             |
| T-02-05   | Elevation of Privilege | /api/auth/\* bypass of middleware                               | mitigate    | Skip guard is prefix-only ('/api/auth/') and does not skip data routes; manual review confirms only auth sub-routes are excluded                      |
| T-02-06   | Elevation of Privilege | Refresh token replay (D-09)                                     | accept      | No revocation list per D-09 decision; logout only clears client cookie; 30d window acceptable for Phase 1 MVP                                         |
| T-02-07   | Denial of Service      | Brute force login                                               | accept      | No rate limiting in Phase 1 scope; acceptable for MVP; flag for Phase 2                                                                               |
| T-02-08   | Tampering              | D-04 invite hijack (register with someone else's invited email) | mitigate    | invite check uses email.toLowerCase() consistent with User schema lowercase:true — exact match required; invite record deleted on use (one-time join) |
| T-02-SC   | Tampering              | npm install (bcryptjs, jose)                                    | mitigate    | Packages already installed in Plan 01; slopcheck audit in RESEARCH.md shows no postinstall scripts; no new packages in this plan                      |

</threat_model>
